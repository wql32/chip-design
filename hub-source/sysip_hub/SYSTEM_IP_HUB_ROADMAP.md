## 每次修改的标准流程

1. 修改本地源代码或资产目录。
2. 启动本地服务并检查页面。
3. 运行 Python 编译检查和单元测试。
4. 生成 GitHub Pages 静态快照。
5. 检查 `git diff` 和页面链接。
6. 提交有意义的 commit。
7. 推送到 GitHub。
8. 检查线上页面和关键入口。
9. 在本文件勾选已完成事项，并记录必要的备注。
