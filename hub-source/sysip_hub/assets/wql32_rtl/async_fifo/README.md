# 异步 FIFO（格雷码）

## 用途

在两个独立时钟域之间传输数据。写指针和读指针分别在本时钟域维护，跨域时转换为 Gray code，再通过两级同步器传递。

## 接口行为

- 写入条件：`wr_en && !full`。
- 读取条件：`rd_en && !empty`。
- `full` 位于 `wr_clk` 域，只应在写时钟域使用。
- `empty` 位于 `rd_clk` 域，只应在读时钟域使用。
- `rd_data` 是当前读地址对应的组合输出，只有 `empty=0` 时有意义。

## 参数约束

- `DEPTH` 必须是 2 的幂。
- 当前 full 比较使用两个最高 Gray bit，建议 `DEPTH >= 4`。
- `DATA_WIDTH` 需要与目标双口 RAM 或寄存器阵列实现匹配。

## 时序与 CDC 说明

指针跨域同步需要两个目标时钟周期，因此 full/empty 的撤销存在同步延迟。这是异步 FIFO 的保守行为，不代表额外数据丢失。数据本体通过双口存储器传递，控制同步器不能替代存储器的 CDC 结构。

## 使用限制

- `wr_rst_n` 和 `rd_rst_n` 可以独立拉低，但复位释放应分别在各自时钟域同步。
- 当前 `rd_data` 为异步读形式，能否推断为目标工艺 RAM 取决于综合工具和 RAM 模板。
- 没有 overflow/underflow pulse；非法请求会被内部屏蔽。
- 没有 almost-full、almost-empty 或可用深度输出。
- 集成前应检查 Gray pointer synchronizer 的 CDC 属性和约束。

## 建议检查场景

复位释放、写快读慢、读快写慢、写满后继续请求、读空后继续请求、指针回绕，以及两个复位不同时释放。
