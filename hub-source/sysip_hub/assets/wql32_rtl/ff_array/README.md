# 寄存器阵列

## 当前结论

2026-10-21 修复输入级分支不完整、多重驱动和读输出驱动。保留 ff_array 接口和历史文件名 ff_arrary.v。状态 **Constrained**，实际 RTL 仿真通过。

## 参数与复位

DATA_WIDTH、ARRAY_DEPTH 至少为 1；ADDR_WIDTH 至少为 max(1, ceil(log2(ARRAY_DEPTH)))。FLOP_IN/FLOP_OUT 取 0 或 1。低有效同步复位清输入、输出寄存级；END_OF_LIST 保留未使用。

写使能、地址和数据整体经过可选输入寄存级，不能只延迟部分字段。

## 读写与流水语义

| 配置 | 行为 |
| --- | --- |
| FLOP_IN=0 | 当前输入在本次上升沿执行写操作 |
| FLOP_IN=1 | 本次采样输入，后续上升沿执行已寄存的写操作 |
| FLOP_OUT=0 | 当前内部有效读地址组合选数，禁止读、复位或越界时为零 |
| FLOP_OUT=1 | 上升沿在内部 ren 有效时采样，禁止读保持，复位清零 |

组合读在输入级更新后反映新地址，不能把所有配置都解释为固定周期读延迟。同地址读写时，寄存输出采样旧内容；组合读在写入后反映新内容。越界写忽略、越界有效读为零。寄存输出保持不表示有新数据。

## 初始化与实现边界

阵列本身不复位，无 valid 位，必须先写后读；未初始化 entry 未定义。复位不会抹除已经写入的阵列。保留原版权说明，不改变原授权。

这是 FF 阵列，不保证推断成 SRAM；读选择器、面积和时序需要目标实现评估。
