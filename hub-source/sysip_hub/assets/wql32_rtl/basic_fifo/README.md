# 基础同步 FIFO

## 当前结论

2026-10-21 修复编译错误、非法读写保护、计数器边界及非 2 的幂回绕。状态为 **Constrained**：实际 RTL 仿真通过，未进行综合或时序签核。

## 接口与参数

单时钟，i_rst_n 低有效同步复位，需在上升沿采样。复位清空指针与占用数，不清空阵列。FIFO_WIDTH >= 1、FIFO_DEPTH >= 1；AFULL_DEPTH 建议在 0 到深度之间，o_afull 在占用达到阈值时置位。FIFO_NAME 保留未使用。

i_we/i_wdata 为写请求，i_re 为读请求，不是完整 ready/valid 接口。o_rdata 是组合队首，消费者在有效读的上升沿采样；空或复位时输出零。

## 接受条件与边界

```text
read_fire  = i_rst_n && i_re && !o_empty
write_fire = i_rst_n && i_we && (!o_full || read_fire)
```

| 边界 | 行为 |
| --- | --- |
| 满且只写 | 拒绝写、不覆盖数据，overflow=1 |
| 满且同时读写 | 读旧队首，接收新写入，占用不变 |
| 空且只读 | 拒绝读，underflow=1 |
| 空且同时读写 | 无旁路：拒绝读、接受写，underflow=1 |
| 正常同时读写 | 各接受一次，占用不变 |

告警为当前请求的组合输出，不是粘滞错误位；指针只随真实操作更新，显式按 FIFO_DEPTH 回绕。

## 架构与复用边界

保留独立读写指针、组合读阵列及计数器。修复原指针拼写、拼接语法、越界及非法请求改变状态的问题。满状态替换依赖边沿前队首可读；若改用 SRAM，必须重新确认同地址读写和读延迟。
