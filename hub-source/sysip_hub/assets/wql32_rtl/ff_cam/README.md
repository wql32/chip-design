# 寄存器 CAM

## 当前结论

2026-10-21 修复输入级缺失、写错误依赖读使能、无效 entry 命中及搜索结果错误连接。状态 **Constrained**，实际 RTL 仿真通过。

## 接口、参数与流水

DATA_WIDTH、ARRAY_DEPTH 至少为 1，ADDR_WIDTH 足以表示所有 entry 且至少为 1。FLOP_IN/FLOP_OUT 取 0 或 1，END_OF_LIST 保留未使用。低有效同步复位清数据、valid 和流水寄存器。

写、读、清除、搜索控制及对应地址、数据和 key 完整经过可选输入级。FLOP_IN=1 增加输入采样级；FLOP_OUT=1 在上升沿采样内部有效读/搜索结果，无请求则保持。

## 读写、清除和匹配规则

- 写入与读使能独立；写入同时置 entry valid。
- 清除将 entry 的数据、valid 清零。
- 同 entry 同拍写清时**写优先**；不同 entry 可各自更新。
- 无效或越界读返回零；越界写/清除忽略。
- 搜索仅比较有效 entry，重复 key 选择最低索引。
- 组合输出在禁止时为零，寄存输出在禁止时保持；复位清零。
- 寄存读/搜索取边沿前内容，同拍写入只影响后续组合结果或下一次寄存采样。

## 旧接口的信息缺失

只有 o_saddr、没有 match-valid，**无命中与命中地址 0 都编码为 0**，不能区分。保留接口无法消除此限制；需要区分的集成应扩展 hit-valid，不能直接将 saddr=0 判为未命中。

## 架构与复用边界

FF 存储 + 并行比较 bitmap + 最低位置优先选择器，不再误用 onehot2bin 处理多命中。大深度下比较扇出和优先路径需综合/STA 评估；接口没有 pending 队列或 ready/valid 反压。
