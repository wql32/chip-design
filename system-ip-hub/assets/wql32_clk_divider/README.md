# 可配置整数分频器

## 当前结论

2026-10-21 修复奇数分频多过程驱动和输出自引用，使用独立正负沿寄存器组合波形。状态 **Constrained**：数字 RTL 仿真通过，不代表时钟实现签核。

## 接口与配置

| 模式 | 合法参数 |
| --- | --- |
| DIV_MODE=0 | DIV_FACTOR >= 2 且为偶数 |
| DIV_MODE=1 | DIV_FACTOR >= 3 且为奇数 |
| 其他模式或不匹配因子 | 输出固定零，不旁路 |

clk_in 为输入时钟，rst_n 低有效异步复位，clk_en 在输入正沿采样。复位清计数和波形状态；释放需满足恢复/移除要求。

## 波形与使能规则

偶数模式每 DIV_FACTOR/2 个被使能正沿翻转一次，禁止时保持计数与输出。

奇数模式正沿更新相位、clk_pos；紧随负沿按前一正沿采样的使能完成 clk_neg 更新，输出为两者 OR。**禁止使能不会取消已采样的半周期动作**，最后一个被允许正沿对应的负沿仍可能改变输出，之后保持。

连续使能且输入时钟理想占空比 50% 时，稳定输出周期为 DIV_FACTOR 个输入周期，占空比 50%。暂停可能停高或停低，不承诺暂停时占空比；异步复位可截断高脉冲。

## 实现与使用限制

- clk_en 必须满足输入正沿采样时序，不接受任意异步控制。
- 不支持动态/非整数分频、旁路或无毛刺时钟切换。
- 正负沿路径只有半周期预算，实际门延迟影响脉宽和占空比。
- 作为真实时钟使用必须补 generated-clock、STA、最小脉宽、CTS 和复位检查，必要时替换为工艺认可时钟单元。
- RTL 波形正确不能证明 OR 组合时钟在所有工艺与布线下安全。

## 验证记录

Icarus Verilog 执行 tb/tb_divider.sv，偶数因子 2/4/8、奇数 3/5/7/9，以及非法 (因子,模式)=(1,1)/(3,0)/(2,1)/(5,2)，共 11 组。独立按有效输入边沿计算半周期波形，逐正负沿检查连续运行、300 次随机使能、暂停恢复和异步复位。pyslang 12.0.0 展开通过。
